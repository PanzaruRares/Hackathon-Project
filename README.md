# SightLine

Testează o campanie pe panouri stradale înainte să plătești: vizibilitate, lizibilitate, atenție și cost real pe impresie, pentru fiecare locație.

## Pornire rapidă

1. `git clone` acest repo.
2. Copiază `.env.example` în `.env` și pune cheile (nu se urcă pe GitHub).
3. Intră în folderul tău (`unity/`, `backend/`, `ai/` sau `web/`) și pornește Claude Code acolo.

Contextul complet pentru oameni și agenți e în [`CLAUDE.md`](CLAUDE.md). Formatele de date sunt în [`contracts/`](contracts/).
